# NebulaKit Agent Notes

## Initial Template Customization Gate

Before handling the user's first substantial request, check [INITIAL_CUSTOMIZATION_STATUS.md](INITIAL_CUSTOMIZATION_STATUS.md).

- If the status is `pending`, recommend the workflow in [docs/INITIAL_CUSTOMIZATION.md](docs/INITIAL_CUSTOMIZATION.md) before doing other feature work.
- If the user explicitly asks to perform that customization, proceed with it.
- If the status is `complete`, do not raise the reminder again unless the user asks to revisit branding or documentation cleanup.

When the initial customization work is completed, update [INITIAL_CUSTOMIZATION_STATUS.md](INITIAL_CUSTOMIZATION_STATUS.md) so future sessions know the template setup has already been handled.
